# Runbook — Cobrança

1. Consulte a fatura e confirme o valor, a competência e o status.
2. Se houver cobrança duplicada, registre a evidência e peça reembolso.
3. Reembolso **sempre** requer aprovação humana do financeiro; nunca prometa prazo.
4. Para troca de cartão, oriente o cliente a atualizar no portal; não solicite dados completos.
5. Para dúvida de plano, consulte a tabela vigente e responda com a fonte.

Ferramentas: `consultar_fatura`, `solicitar_reembolso` (aprovação), `orientar_cliente`.
