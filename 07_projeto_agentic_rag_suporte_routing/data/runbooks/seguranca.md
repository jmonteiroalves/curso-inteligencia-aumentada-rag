# Runbook — Segurança

1. Classifique imediatamente como incidente de segurança; não faça reset de senha como primeira ação.
2. Preserve logs e evidências; não acesse dados além do necessário.
3. Escale para o time de segurança e para o DPO se houver dados pessoais.
4. Não bloqueie contas, não exclua registros e não comunique publicamente sem aprovação humana.
5. Registre linha do tempo, escopo, clientes afetados e ações tomadas.

Ferramentas: `escalar_seguranca` (handoff), `bloquear_conta` (aprovação), `notificar_dpo`.
