# Runbook — Acesso

1. Verifique a identidade do solicitante por um canal corporativo.
2. Nunca peça senha; use o fluxo de reset ou desbloqueio.
3. Para conta bloqueada, confirme o titular e desbloqueie com registro.
4. Se houver suspeita de comprometimento, trate como segurança e escale.
5. Exija MFA e aplique o menor privilégio.

Ferramentas: `verificar_identidade`, `reset_senha`, `desbloquear_conta`.
